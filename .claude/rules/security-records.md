# 기록·보안 기준

<!-- claude-drafted: 2026-11-02 -->

1. **비밀값 금지:** API 키, 토큰, 비밀번호, 개인키(`*.pem`, `*.key`, `.env`)는 코드·문서·커밋에 포함하지 않습니다.
2. **개인 경로·계정 마스킹:** 터미널 출력 로그나 스크린샷을 문서에 넣을 때 로컬 사용자 경로(`/Users/...`), 실제 이메일 주소, 개인 IP 등은 `<PROJECT_ROOT>`, `<YOUR_EMAIL>` 등으로 치환하거나 상대 경로 기준으로 기록합니다.
3. **실제 확인 기록 구분:** 직접 터미널에서 실행해 확인한 결과만 검증 로그에 기록합니다.
4. **커밋 전 기계 확인:** 커밋 전 `bash .claude/hooks/check-secrets.sh --staged`를 실행해 비밀값 패턴이 없는지 확인합니다.
