# docs/** 및 마크다운 편집 규칙

<!-- claude-drafted: 2026-11-02 -->

1. **모든 상대 링크는 저장소 안에 실제로 존재하는 파일을 가리켜야 합니다.**
2. **앵커(`#절-이름`) 링크 대신 가급적 파일 단위 상대 링크(`docs/01-verification-log.md`)를 사용합니다.**
3. **체크리스트 상태(`README.md`의 `[x]`, `PASS / FAIL`)를 바꿀 때는 대응하는 상세 문서(`docs/01~03.md`)에 실제 실행 흔적이나 설명이 채워졌는지 먼저 확인합니다.**
4. 편집 후에는 `bash .claude/hooks/check-links.sh`로 깨진 링크가 0건인지 확인합니다.
